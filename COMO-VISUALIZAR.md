# Como abrir a documentação do WeLuvCode

Guia para quem só quer **ler** a documentação. Não é preciso instalar nada nem
saber programar: o material é uma página que abre no navegador.

Leva cerca de 5 minutos.

---

## Passo 1 — Ter acesso ao repositório

A documentação fica em um repositório privado no GitHub:

`https://github.com/marcelleguine-duranium/wlc-documentation`

Você precisa de:

- uma **conta no GitHub**
- que essa conta tenha sido **liberada** para este repositório

Se ao abrir o endereço aparecer uma página de erro 404, não é engano seu: quer
dizer que sua conta ainda não tem acesso. Peça a liberação informando o seu nome
de usuário do GitHub.

## Passo 2 — Baixar o conteúdo

1. Abra o endereço acima, já logado no GitHub
2. Clique no botão verde **Code**, no canto direito acima da lista de arquivos
3. No menu que abrir, clique em **Download ZIP**
4. O arquivo vai para a sua pasta de Downloads

## Passo 3 — Descompactar

- **Windows** — clique com o botão direito no arquivo baixado e escolha *Extrair
  tudo*
- **Mac** — dê dois cliques no arquivo; a pasta aparece ao lado

Você vai ficar com uma pasta chamada `wlc-documentation-main` (ou parecida).

## Passo 4 — Abrir

Dentro dessa pasta:

1. Entre na subpasta **`site`**
2. Dê dois cliques no arquivo **`index.html`**

A documentação abre no seu navegador. Pronto.

---

## Como usar a página

- **Menu à esquerda** — as seções, agrupadas em dois módulos: *Painel Principal*
  e *Painel Admin*. Clique no nome do módulo para expandir ou recolher
- **Busca no topo** — procura em toda a documentação; atalho `Ctrl+K`
  (`Cmd+K` no Mac)
- **Rodapé de cada página** — botões para ir à seção anterior ou à próxima

A página funciona sem internet: depois de baixada, dá para consultar offline.

---

## Se algo não funcionar

**As imagens não aparecem.** O arquivo `index.html` foi movido para fora da
pasta. Ele precisa continuar dentro de `site`, junto das outras pastas, porque
busca as imagens ali ao lado. Volte o arquivo para o lugar, ou baixe o ZIP de
novo.

**O arquivo abre em um editor de texto, cheio de código.** O computador associou
`.html` ao programa errado. Clique com o botão direito no arquivo, escolha *Abrir
com* e selecione Chrome, Edge, Firefox ou Safari.

**Aparece 404 ao abrir o endereço do GitHub.** Sua conta ainda não tem acesso ao
repositório. Peça a liberação.

---

## Para receber as atualizações

O conteúdo muda quando o produto muda. Não existe atualização automática: para
ter a versão mais recente, repita os passos 2 a 4 e substitua a pasta antiga.
